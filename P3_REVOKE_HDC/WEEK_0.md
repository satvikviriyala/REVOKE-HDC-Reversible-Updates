# P3 REVOKE-HDC: Week 0 Reading

Read these three papers only before the first group meeting. Download the PDFs from the links below.

1. A Survey on Hyperdimensional Computing, Part I: Models and Data Transformations: `https://arxiv.org/abs/2111.06077`. Read the introduction and the explanations of bundling, binding, permutation and similarity. Notice what each operation preserves and what it discards.
2. OnlineHD: Robust, Efficient, and Single-Pass Online Learning Using Hyperdimensional System: `https://www.ics.uci.edu/~mohseni/papers/DATE21_OnlineHD_Imani.pdf`, Hernandez-Cano et al. Read the HDC classification overview and adaptive-training method. Notice how a class prototype changes after each sample.
3. QuantHD: A Quantization Framework for Hyperdimensional Computing: `https://par.nsf.gov/servlets/purl/10169532`, Imani et al. Read the framework overview and binary/ternary quantisation method. Notice what is lost when a signed class vector becomes a compact binary vector.

Bring one page containing an 8-dimensional Hamming-distance example and your answer to this question: **why can two different signed counts produce the same stored bit?**
