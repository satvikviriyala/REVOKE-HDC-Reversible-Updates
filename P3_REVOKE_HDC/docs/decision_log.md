# Decision Log: 16 Week 1 Closed Items - REVOKE-HDC

This log formally closes all 16 items identified in `PROJECT_PLAN.md` Section 10 ("Risks and open decisions to close in Week 1"). Every item carries a confirmed decision, engineering rationale, assigned owner, and verified status.

| # | Item Description | Status | Confirmed Decision & Parameters | Rationale & Impact | Owner |
|:---:|---|:---:|---|---|:---:|
| **1** | **Encoder and Dataset Choice** | **CLOSED** | Multi-modal activity benchmark with two streams: Modality A (Vision-style, 32 continuous features) and Modality B (IMU-style, 16 accelerometer/gyro features). 4 classes: `0: Idle`, `1: Normal Operation`, `2: High Load`, `3: Critical State`. Random projection continuous item memory to $D=4096$ with deterministic seed `0xREV0KE26`. | Directly matches the two-modality agreement check ($h_A, h_B$) and 4-class frozen configuration. Allows realistic synthetic/recorded sensor replay without gigabyte downloads. | Reference Owner |
| **2** | **Residue Range and Update Alphabet** | **CLOSED** | Signed 4-bit two's complement for residue ($-8..+7$). Update contribution alphabet: signed 4-bit two's complement ($-8..+7$). | Satisfies $\text{residue\_bits} \ge \lceil\log_2(2 \cdot |u|_{\max})\rceil$. Since 4-bit two's complement cannot encode $+8$ without overflow into sign bit, conceptual $+8$ is refused as `refused_residue` (4). Keeps journal entry at exactly 2 bytes (12b dim + 4b residue). | Hardware Owner |
| **3** | **Duplicate Dimension Indices** | **CLOSED** | Duplicate dimension indices within one candidate packet are strictly prohibited and cause entire packet refusal with `refused_duplicate` (Outcome 6). | Prevents multiple contradicting mutations or double-flipping within a single commit cycle. Enforced by a 4096-bit parse scoreboard. | Verification Owner |
| **4** | **Entry Ordering in Packet & Record** | **CLOSED** | Preserve stream order within packet and journal record. Datapath uses 64-bit word write-mask combining to group same-word entries into single-cycle memory operations. | Preserves arrival sequence while eliminating multi-cycle memory hazards for dimensions landing in the same 64-bit word. | RTL Owner |
| **5** | **Combining Multiple Bit Changes to One 64-Bit Word** | **CLOSED** | Group entries by word index ($d \gg 6$). For each unique word, construct 64-bit `wr_mask` and `wr_data`. Execute masked read-modify-write in one cycle per unique word. | Avoids multiple read-modify-write cycles to the same BRAM word, preventing intra-packet data hazards. | RTL Owner |
| **6** | **Margin / Agreement Admission Rule ($\theta_A, \theta_B$)** | **CLOSED** | Deterministic rule: $h_A == h_B == \text{class\_id} \land m_A \ge \theta_A \land m_B \ge \theta_B$. Calibrated margins: $\theta_A = 128$, $\theta_B = 128$ on 8-bit scale ($0..255$). | Ensures both modalities agree on class identity with high confidence before mutating state. Matches `PROJECT_PLAN.md` Section 8 demonstration values. | Reference Owner |
| **7** | **Journal Allocation Structure** | **CLOSED** | Byte-addressable append-only ring buffer in on-chip BRAM + fixed-depth Record Index Table with per-class head pointers. | Ring buffer allows variable-length sparse records ($16 + 2F$ bytes). Index table provides $O(1)$ reverse-commit order lookup and state tracking. | System Owner |
| **8** | **Ring Wrap Behaviour** | **CLOSED** | **Pad-to-end and restart at offset 0**. If the remaining contiguous bytes between `head_ptr` and the physical ring end are less than required record size $R(F)$, the allocator inserts a pad marker and allocates the record starting at offset 0. Records NEVER split across physical boundary. | Eliminates complex split-record read/write state machines in RTL. Sizing sheet confirms padding waste is $< 0.1\%$ of total 256 KiB BRAM ring. | RTL Owner |
| **9** | **Per-Class Reverse-Order Check** | **CLOSED** | Restoration request must target `slot_id == class_head_slot[class_id]`. Attempting to restore an earlier record while a newer active record exists returns `refused_ordering` (Outcome 7). | Guaranteed bit-for-bit exact reversal by unwinding updates in exact LIFO order per class. Arbitrary order is out of scope. | Verification Owner |
| **10** | **Break-Even Formula Sizing** | **CLOSED** | Sparse record $R(F) = 16 + 2F$ bytes. Full snapshot = 512 bytes. Break-even inequality: $16 + 2F < 512 \iff 2F < 496 \iff F < 248$. | For all legal packets ($F \le 96$), $R(F) \le 208 \text{ bytes}$, which is less than $40.6\%$ of a full snapshot. | System Owner |
| **11** | **PL Target Clock & Packet Rate** | **CLOSED** | Target clock: 100 MHz (period 10.0 ns) on KV260 PL. Sustained packet throughput: $\ge 50,000$ packet decisions/sec. | Easily met by 100 MHz datapath (requiring $< 150$ cycles per 96-entry packet parse and masked commit). | FPGA Owner |
| **12** | **Journal BRAM Capacity** | **CLOSED** | 256 KiB (262,144 bytes) BRAM ring buffer. Sized for $> 1,000$ typical records ($F \approx 40 \implies 96 \text{ B}$) or 1,260 maximum-size records ($F=96 \implies 208 \text{ B}$). | Provides ample headroom for sustained online training batches before wrapping or retirement. Consumes 64 36Kb BRAM blocks on KV260. | Hardware Owner |
| **13** | **Record Index Table Depth ($N$)** | **CLOSED** | $N = 1024$ simultaneously indexable live/retired record slots across all 4 classes. `slot_id` width: 10 bits ($0..1023$). | Supports complete audit trail for 1,000+ continuous updates. | System Owner |
| **14** | **Trace Buffer Depth** | **CLOSED** | 512 entries of 8 bytes each = 4 KiB BRAM (1 Block RAM). Accessible via AXI-Lite `TRACE_POP` register (`0x30`). | Sufficient to capture complete Section 8 demonstration sequence without overflowing or losing trace records. | Verification Owner |
| **15** | **CRC-16 Polynomial** | **CLOSED** | CRC-16/CCITT-FALSE: polynomial `0x1021`, initial `0xFFFF`, no reflection (refin=False, refout=False), xorout `0x0000`. | Industry standard, robust detection of multi-bit burst errors, clean single-LUT implementation per bit slice. | System Owner |
